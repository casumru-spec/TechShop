# TechShop

**TechShop** — Android-приложение для автоматизации работы компьютерного магазина. Позволяет управлять складом комплектующих, базой клиентов и сотрудников, а также оформлять заказы на сборку ПК с контролем остатков.

---

## 🎥 Демонстрация

В папке `demo/` находится видеофайл **`demo.mp4`**, демонстрирующий основные сценарии работы приложения.

---

## 🛠 Стек технологий

* **Язык:** Kotlin
* **UI:** Jetpack Compose, Material 3
* **Архитектура:** MVVM, Single Activity
* **База данных:** Room (SQLite), KSP
* **Асинхронность:** Coroutines, Flow

---

## ⚙️ Основные возможности

* **Заказы и склад:** Оформление заказа и списание комплектующих происходит в одной транзакции. Если товара не хватает — заказ не сохраняется.
* **Целостность данных:** На уровне базы данных настроены SQL-триггеры, которые запрещают уход остатков в минус и следят за корректностью цен.
* **Дизайн:** Кастомная тема оформления в стиле «печатной платы» (PCB) с анимацией дорожек и светодиодными индикаторами.
* **Поиск:** Умный поиск по всем сущностям без учёта регистра.

---

## 📂 Структура

* `app/` — исходный код приложения (пакеты `data` и `ui`)
* `apk/` — готовый для установки APK-файл (`TechShop.apk`)
* `demo/` — видео с демонстрацией работы

---

## 🚀 Запуск

1. Откройте проект в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Запустите на эмуляторе или устройстве (Android 7.0+). При первом запуске БД заполнится тестовыми данными.
